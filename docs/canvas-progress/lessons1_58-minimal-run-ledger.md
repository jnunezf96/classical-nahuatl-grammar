# Lessons 1–58 minimal run ledger

This is a planning ledger, not grammar authority. Canvas supplies the grammar. The atom ledger supplies the fixed denominator. Examples prove rules but never limit productive Source entry.

For every lesson:

- Run only the subjects and contrasts that the lesson actually names.
- Cross two dimensions only when the lesson states that they interact.
- Check the exact typed Source, grammatical operation, and Result—not merely route acceptance.
- Turn an explicit restriction or contrast into a negative check.
- Give reading-only claims a visible cue or guide; do not invent a generator route.
- Expose only genuine choices. Derived class, shape, agreement, order, and realization facts remain automatic unless Canvas presents a real alternative.
- Verify the owner, contradiction check, visible cue, and browser cache path before calling the lesson complete.

## Completion rule

A lesson is not complete merely because all of its atoms have jobs. It is complete only when every named topic above has its required exact run, every stated restriction has a negative run, every reading job is visible, and no unmentioned dimension has been added to the test matrix.
