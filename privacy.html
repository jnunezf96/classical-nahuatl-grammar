Privacy

Grammar OS has no accounts, advertising, analytics, or server-side submission of the Classical Nahuatl text you enter. Grammar work is computed in your browser.

Information stored on your device

The site may use browser storage for presentation preferences. Copy actions write to the clipboard only when you request them.

Optional private play recording

Manufacturer mode includes an optional play recorder. It remains completely off until you confirm that everyone being observed agreed and press Start. While running, it records masked page changes, clicks, scrolling, action timing, and viewport size. Typed inputs and displayed grammar are masked; the accompanying play report replaces Source, Result, and control values with nontextual states and safe control IDs. The recording stays only in the current tab, is never uploaded or placed in browser storage, and exists outside the site only if you deliberately download the stopped recording. You can discard it instead. If someone invited you to participate, give the downloaded JSON file to that person. It records no audio or video.

Third-party resources

The interface requests Fraunces and Space Grotesk font files from Google Fonts. That request is subject to Google's privacy practices. The optional recorder is a self-hosted open-source browser module; it does not contact a recording service. No other third-party runtime service is required.

Hosting

GitHub Pages hosts the public site. GitHub states that it logs and stores each visitor's IP address for security purposes, whether or not the visitor is signed in. See GitHub Pages data collection.
